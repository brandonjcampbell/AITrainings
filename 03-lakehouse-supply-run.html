Lakehouse Supply Run

The region's records survived in one fortified depot: Databricks. This manual covers what's inside it, how to get a gate pass (a personal access token), and how to pull supplies (data) out with Python without leaving the gate open behind you.

Who it's for

Engineers and analysts who need to understand Databricks and pull data from it in code.

Time

60 to 90 minutes: 30 on concepts, 15 on token setup, 30+ hands-on in Python.

Bring

A Databricks workspace login, Python 3.9 or newer, and pip.

Part 1 · The depot

What Databricks is

Databricks is a cloud data platform that runs on AWS, Azure or GCP. It combines a data lake with a data warehouse, which is why it calls itself a lakehouse. You don't run any servers yourself. You ask for compute, it spins up, you do the work, and it spins down. Think of it as a depot with four layers. Select each one.

  • Compute and storage are separate.

    The supplies sit in cloud storage. You only run the generators when you query.

  • Unity Catalog is the gatekeeper.

    If you can't see a table, it's almost always a missing permission grant, not a broken connection.

  • From outside, use a SQL warehouse.

    It's the simplest, cheapest and fastest-starting door into the data.

Part 2 · Gate pass

Get a personal access token

A personal access token (PAT) gets you through the gate from outside the web UI. It works like a password. Anyone holding it walks in as you.

Issue the pass
  1. Click your username or avatar in the top-right corner, then Settings.
  2. In the left menu, click Developer.
  3. Next to Access tokens, click Manage.
  4. Click Generate new token.
  5. Enter a comment, like laptop python scripts, so you can recognize it later.
  6. Set a lifetime in days. Shorter is safer. Your admin may enforce a maximum.
  7. Click Generate.
  8. Copy the token now and store it somewhere safe. It's shown once. If you lose it, revoke it and make a new one.

Tokens look like dapi followed by a long hex string. Menu labels can shift between Databricks releases.

No "Access tokens" option, or it's greyed out? Your workspace admin has turned off PATs or hasn't given you permission. Ask for the "Can Use" token permission, or ask whether OAuth is required instead.
Gate pass rules
  • Never hard-code a token in a script, notebook or commit. Use environment variables or a secrets manager.
  • Never share a token. One per person, per machine or purpose.
  • Unused tokens are revoked automatically after 90 days on most workspaces. Expect to rotate.
  • Revoke at once if a token is ever pasted into chat, a ticket or a log: Settings → Developer → Access tokens → Manage.
  • For automation (CI, scheduled jobs, shared services) use a service principal, so pipelines don't break when someone leaves camp.

      # install
pip install databricks-sql-connector pandas databricks-sdk

# env vars
DATABRICKS_SERVER_HOSTNAME   # Compute → SQL Warehouses → Connection details
DATABRICKS_HTTP_PATH         # same place, starts with /sql/1.0/warehouses/
DATABRICKS_TOKEN             # Settings → Developer → Access tokens → Generate

# query
from databricks import sql
with sql.connect(server_hostname=..., http_path=..., access_token=...) as c:
    with c.cursor() as cur:
        cur.execute("SELECT ... WHERE x = :v", {"v": 1})
        df = cur.fetchall_arrow().to_pandas()

# naming
catalog.schema.table      # always three parts in Unity Catalog
